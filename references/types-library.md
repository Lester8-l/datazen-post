# 懶人包類型庫（**流程第一步：先讓用戶揀做邊種**）

## 為什麼要有這一步

「出一份懶人包」唔係一個足夠清楚嘅指令。資訊類、新聞類、MPF 類，
**同樣係三層結構，但內容規則、合規要求、預設版型、配文寫法都唔同**：

| | 資訊懶人包 | 新聞解讀 | MPF / 強積金 |
|---|---|---|---|
| 事實來源 | 一份長期有效的資料 | 一件新近發生嘅事 | 官方制度與統計 |
| 時效 | 低（幾個月內有效） | **高（幾日內）** | 中（每年更新） |
| 主動權 | 你揀題材 | 新聞揀你 | 你揀時機（報稅季、年結） |
| 最大風險 | 數字過時 | 把方向性事件寫成已落實 | 把投資資訊寫成投資建議 |
| 預設版型 | **L1 軟性** | **L2 行動** | **L3 輪播** |

所以**第一步必須先確認類型**，唔係邊做邊問。

---

## 流程定義（SKILL.md 第一步）

```
用戶提出要做懶人包
        ↓
【第一步】用 AskUserQuestion 讓佢揀類型（下方 8 類，附建議版型）
        ↓
    確認類型後 → 再問／確認以下三項（一次問完）
        ① 素材：貼文字 / 只講題目
        ② 結尾：軟性（純分享）/ 引導（連去服務）
        ③ 版型：用建議值 or 自己揀
        ↓
    出文字稿 ＋ WhatsApp 配文 → 等確認
        ↓
    確認後 → 出 HTML → 跑四支檢查 → 出 PNG
```

**注意**：類型確認之前，唔好開始寫內容。
寫錯類型等於整份重做，比多問一句貴得多。

## 八類懶人包

### 1. 資訊懶人包（一般知識）

- **一句定義**：把一份長期有效嘅資料，變成客戶睇得完嘅三點
- **素材**：研究報告、行業統計、政府資料、教科書式知識
- **切入角度**：概念澄清 / 常見誤解 / 「其實係咁運作」
- **預設版型**：**L1 單張軟性**
- **例子**：「醫療開支點解越嚟越重」——見 `examples/`
- **合規注意**：數字必須標年份；唔可以寫成「一定」「必然」
- **建議來源**：政府統計處、監管機構年報、大學研究、國際組織報告

### 2. 新聞解讀

- **一句定義**：一件新近發生嘅事 + 佢對客戶嘅實際意義
- **素材**：新聞報道、政策公布、財經消息
- **切入角度**：**「呢件事關你咩事」**——新聞本身唔重要，影響才重要
- **預設版型**：**L2 單張行動**（新聞自帶時效緊迫感，適合接下一步）
- **例子**：「監管新規對保單持有人嘅影響」
- **合規注意（最高）**：
  - **政策階段一定要寫清楚**：建議 / 諮詢中 / 草案 / 已通過 / 已生效
  - 唔可以預測後續走向
  - 唔可以評論其他公司產品
  - 時效性強 → 卡片要寫明確日期，過期就唔好再發
- **建議來源**：政府新聞公報 (info.gov.hk)、保險業監管局、積金局、金管局、主要媒體財經版

### 3. MPF / 強積金資訊

- **一句定義**：講清楚制度、選項、或一個打工仔容易忽略嘅位
- **素材**：積金局官方資料、強積金統計摘要、DIS 相關規定
- **切入角度**：
  - 預設投資策略（DIS）係咩、邊個適合
  - 自願性供款扣稅上限
  - 「轉工之後舊 MPF 去咗邊」
  - 基金開支比率（FER）點睇
  - 強積金以外的第二層缺口
- **預設版型**：**L3 輪播 3 頁**（制度性內容需要分層講）
- **合規注意**：
  - 涉投資 → **必須有「投資涉及風險」**，基金表現不得承諾
  - 提到扣稅額度 → **必須寫「以積金局／稅務局最新公布為準」**
  - 唔可以推介特定基金或受託人
  - 唔可以聲稱「穩健」「保本」
- **建議來源**：積金局（mpfa.org.hk 官方統計及教育素材）、稅務局

### 4. 醫療健康資訊

- **一句定義**：一個健康趨勢或醫療開支現象，接去「你可以點準備」
- **素材**：醫療統計、公共衞生研究、醫療成本數據
- **切入角度**：醫療成本趨勢 / 疾病年輕化 / 公營私營落差 / 康復期收入缺口
- **預設版型**：**L1 單張軟性**
- **合規注意（極高）**：
  - **嚴禁寫成醫療建議**：唔可以寫「呢隻藥有效」「你應該去驗」
  - 必須有「不構成任何醫療建議」
  - 唔可以引用未經核實嘅醫療傳言
- **建議來源**：衞生署、醫院管理局、香港癌症資料統計中心、大學醫學院

### 5. 退休規劃資訊

- **一句定義**：把「退休要幾多錢」拆成睇得明嘅幾幅圖
- **素材**：人口統計、生命表、退休開支研究
- **切入角度**：長壽風險 / 退休年期比上一代長 / 醫療與長期照顧係最難預算嘅一塊 / 通脹侵蝕固定收入
- **預設版型**：**L3 輪播 3 頁**
- **合規注意**：涉及投資回報 → 標「過往表現不代表將來」；年金數字標「非保證」
- **建議來源**：政府統計處、積金局、香港年金公司、OECD Pensions at a Glance

### 6. 稅務 / 扣稅資訊

- **一句定義**：報稅季前，講清楚有咩可以扣、扣幾多、需要咩條件
- **素材**：稅務局公告、扣稅產品官方定義
- **切入角度**：自願醫保（VHIS）保費扣稅 / 延期年金扣稅 / 強積金自願供款扣稅
- **預設版型**：**L2 單張行動**（季節性強，附明確下一步）
- **時機**：每年 4–6 月報稅季
- **合規注意**：額度與合資格定義**必須寫「以稅務局最新規定為準」**
- **建議來源**：稅務局（ird.gov.hk）、醫務衞生局（VHIS 官方網站）

### 7. 理財概念

- **一句定義**：教一個客戶唔識但需要識嘅概念（唔係產品）
- **素材**：基礎理財知識、複利 / 通脹 / 風險與回報
- **切入角度**：複利同時間 / 通脹點食咗你嘅錢 / 分散風險 / 應急錢要幾多
- **預設版型**：**L1 單張軟性**
- **合規注意**：**最高風險類型**——最易踩「穩賺／保證回報／像定存」
- **建議來源**：投資者及理財教育委員會（IFEC）、金管局

### 8. 政策解讀

- **一句定義**：政府或監管機構新方向 + 對客戶嘅實際影響
- **素材**：政策文件、諮詢文件、立法會文件
- **切入角度**：受影響嘅係邊個 / 幾時生效 / 過渡期安排
- **預設版型**：**L2 單張行動**
- **合規注意**：
  - **階段必須寫清楚**，唔可以寫成已落實
  - 不評論政策好壞，只講內容與影響
  - 政治敏感題材一律唔做
- **建議來源**：政府新聞公報、政策局官網、立法會網站
