# Data Zen · 品牌與視覺規則

> 這一頁是所有視覺決定的唯一來源。改色、改字、加版型之前先讀完。
> 一句北極星：**以極客邏輯抽乾水份，以沉靜內在安頓人心。**

## 一、品牌輪廓（寫文案時的依據）

| 維度 | 內容 |
|---|---|
| 本質 | 理智規劃 · 安心生活 |
| 身份 | 前 IT 人 × 保單數據整理師 |
| 受眾 | 專業人士、中產家庭、孤兒單持有者、反感硬銷的理性決策者 |
| 口號 | 用前 IT 人的邏輯，講每個人都聽得明嘅保險人話 |
| 相對傳統從業員 | 賣「客觀審視、診斷系統、認知清晰」，不是人情與產品 |
| 相對比價平台 | 有數據拆解力，也有深度傾聽的溫度 |

**Data 支柱**：Debug 視角（合約＝程式碼，逐行剔除冗余）／客觀透明（用數字與條款說話，不恐嚇不人情綁架）／減法思維（去蕪存菁，不是買更多）。
**Zen 支柱**：客觀引導（不追著客戶跑）／邊界感與節奏（每週限量深度諮詢）／終極目標是心裡踏實。

## 二、視覺定位：數據霧（Instrumented Mist）

霧是氣氛，刻度是態度。遠看是一張安靜的圖，近看會發現它一直被量度。

**四件理性元件**（每張卡至少要有一件，否則就退化成「心靈帳號」）：

> 例外：`statement` 宣言卡刻意讓刻度尺退場（`.card[data-type="statement"] .ruler{display:none}`），只靠頂欄做理性框架——宣言要更靜。其餘版型保留刻度尺。

**中文字距一律 ≤ .06em**（硬規則）。只有拉丁字母的 mono label 可用 .14–.2em；**中文落喺標籤位時改用楷體**（`--soft`）＋字距 ≤ .04em——等寬體冇中文字形，fallback 會令中英字體唔同、顯得散。所以 `.top .r` 同 `.end-body .slots` 已改用楷體。

| 元件 | class | 作用 | 注意 |
|---|---|---|---|
| 刻度尺 | `.ruler` | 0–100 刻度，令畫面像被量度過；暗示保障比例 | 數字 15px、`--ink-66`，是裝飾不是內容 |
| 標註括號 | `.bracket` | 工程圖式括號，把一句話拆成可兌現的清單 | 寬度對齊主標，端點向下 |
| 疊加條 | `.bar` | 把比例畫出來（66／34） | 只有「重複」那段用硃紅 |
| 檔案 metadata | `.meta` / `.src` | 等寬字 `3 POLICIES · 47 CLAUSES`，可追溯 | 大寫、字距 .09em |

## 三、色票（不可自行加色）

```
霧底      #46554F → #5C6B65 → #727E77 → #847A6D → #5B635C（163deg 漸層）
主文字    #FFFDF8        次要 .80    裝飾 .66
細線      rgba(255,253,248,.34) / .20
硃紅      #C2553B        淺赭（霧上紅字） #F2C4A6      引用點 #D9644A
```

**硃紅的唯一用途**：標示「重複、冗餘、問題」。它是一支紅筆，不是裝飾色。
一張卡最多兩處；用在別處品牌就散了。

## 四、字體四層

| 角色 | 字體 | 用在哪 |
|---|---|---|
| 標題 | Noto Serif TC 600/700 | 大標、宣言、數字說明 |
| 正文 | LXGW WenKai TC | 內文、表格、清單（有溫度） |
| 手寫 | Iansui | 每張卡最多一句：主張、批註、一句講完 |
| 數據 | JetBrains Mono | metadata、刻度、編號、標籤 |
| 英文數字 | Cormorant Garamond | 34%、頁碼、括號裡的 3 |

**中文字距一律 ≤ .06em。** 只有拉丁字母的 mono label 可以用 .14–.2em。
這一條是硬規則——中文寬字距在細字級會直接毀掉可讀性。

### 字級階梯（只有這 9 級，不得自創）

| 級 | 用途 | 一張卡會用到的組合 |
|---|---|---|
| **18** | 免責細字 | 只在 `.disc` |
| **21** | 標籤、metadata、表頭、編號、刻度 | 幾乎每張 |
| **34** | 次要正文（說明句、事實解釋、CTA） | 需要兩層正文時 |
| **42** | 主要正文（表格行、行動列、宣言副句、領句） | 大部分內容卡 |
| **54** | 次標題（懶人包標題、對照欄主張、封面小標） | 需要中層時 |
| **88** | 大標（封面主標、宣言） | 一張卡一個 |
| **112** | 手寫主張（收尾、清單） | 一張卡一個 |
| **138** | 封面手寫 | 只在封面 |
| **290** | 大數字 | 只在 `number` |

**為什麼是這幾個數字**：手機上卡片約顯示在 390px 寬（0.36 倍）。
42px 的正文在手機是 **15px**，剛好是舒服的閱讀大小；34px 變成 12px，是下限。
21px 的標籤變成 7.6px——所以標籤只能是「標籤」，不可以承載句子。

**不要做的事**：不要出現 25/28/31/36 這種「差兩三 px」的相鄰字級。
相鄰字級太近，讀者感覺不到層級，整張卡就會「又細又平」。

## 五、可讀性紅線（check-contrast.py 會量）

| 項目 | 標準 |
|---|---|
| 正文（< 40px）白字 vs 霧底 | **≥ 4.5:1**（實測 6.2–7.0） |
| 大字（≥ 40px 或 100px 手寫） | ≥ 3:1 |
| 最小字級 | 15px（唯一例外：刻度的 0/25/50/75/100，屬裝飾） |

要壓深霧底來救對比，不要靠加粗或描邊硬撐。
加 `text-shadow` 只能救大字，救不了 20px 的中文。

## 六、插畫與裝飾

**沒有插畫。** 霧、顆粒、網格、刻度、括號本身就是視覺語言。
不要加 Emoji、不要加線稿小圖、不要加有機色塊——它們會把「數據禪」拉回「療癒帳號」。

唯一的裝飾例外：`.grain`（SVG 顆粒）與 `.gridlayer`（90px 網格，靠 mask 淡出）。

## 七、版面預算（1080×1350）

- 內容淨寬：1080 − 74×2 = **932px**
- 可用高度：1350 − 78 − 66 = **1206px**，扣掉 top(60) / ruler(50) / meta(61) ≈ **1035px** 給主體
- `check-fit.py` 量的是 `.frame` 的 `scrollHeight − clientHeight`，**任何溢出都會被 `overflow:hidden` 靜默裁掉**

常用字級：

| 元素 | 字級 | 每行字數（淨寬 932px） |
|---|---|---|
| 封面手寫 `.hand` | 138px | 6 |
| 封面主標 `.title` | 88px | ≤ 10 |
| 宣言 `.st` | 88px | ≤ 10 |
| 數字 `.bignum` | 290px | — |
| 表格 `.tr span` | 42px | ≤ 9（欄寬限制，實際約 8） |
| 懶人包標題 `.pk-title` | 54px | ≤ 16 |
| 懶人包事實 `.facts .t` | 42px | ≤ 16 |
| 懶人包事實 `.facts .d` | 34px | ≤ 26 |
| 對照欄 `.cmp .col .t` | 54px | ≤ 8（欄寬只有 444px） |

**寫稿時就要數**。字級放大之後，每行能放的字的確變少了——
「寧可一開始寫短，不要等他改稿時才發現爆行」。

## 八、兩個模式的差別

| | IG 模式 | 客戶懶人包 |
|---|---|---|
| 張數 | 6–9 | 1 或 3 |
| 受眾 | 陌生人（要停手） | 已認識的客戶（要開對話） |
| 必須有 | 封面 + 收尾 | 每張卡的 `.src` 來源與 `.disc` 免責 |
| 客戶資料 | 一律不可出現 | 一律不可出現（圖會被轉發） |
| 合規 | 涉及保險投資時套用禁詞 | 全套強制，`check-source` + `check-compliance` 都要過 |

## 九、五個最常見的錯

1. **霧太淺** → 白字只剩 3.x:1，手機上糊成一片。壓深，不要加粗。
2. **中文用寬字距** → 看起來「高級」，實際讀不動。
3. **硃紅用超過兩處** → 從「紅筆標問題」變成「裝飾配色」。
4. **每張卡都塞 metadata** → 節奏變平；metadata 是標點，不是句號。
5. **手寫體寫整段** → Iansui 只適合一句。整段請用霞鶩文楷。
