# 圖片生成與圖文排版

## 一、幾時呼叫圖片生成工具

喺文字稿嘅 `[畫面]` 寫低每卡嘅作用、角色動作同留白位置。進入出圖階段後，按畫面需要揀做法。

| 畫面需要 | 做法 |
|---|---|
| 封面或故事頁要新場景、新動作、人物同貓互動，或者需要滿版插畫 | 用圖片生成工具畫一幅完整場景，按第二節輸入角色參考 |
| 確認過嘅底圖要改構圖、光線或角色動作 | 將要改嘅底圖同相關角色參考圖交畀圖片工具做編輯 |
| 用戶指定相片、已有合適素材，或者同一系列已確認嘅空景 | 直接用於排版，調整裁切同圖文位置。獨立肖像可用於個人介紹卡 |
| 複利試算、數據比較、流程或三項重點清單 | 用 HTML／CSS 或程式排版文字及圖表。需要氣氛時，加同系列嘅低細節空景 |
| 卡面以文字或數據為主 | 用品牌標準霧底、線條同留白 |

封面先用一句口語講清讀者關心嘅得益或代價。用戶想先睇畫面方向，先做一張有實際文字嘅封面樣稿。方向確認後，按同一套圖文原則完成餘頁。

## 二、固定角色同系列一致性

1. 先讀[品牌第六節](brand.md)。`assets/characters/lester-reference.png` 用於 Lester，`assets/characters/cat-reference.png` 用於銀灰虎斑貓。工作區欠缺其中一張時，先從用戶已提供嘅品牌素材取得對應原圖，或者請用戶補上。
2. 將畫面出現嘅固定角色圖實際交畀圖片工具。做同系列續頁時，可以加已確認嘅無字封面底圖，延續色溫、光源、透視同畫風。
3. 參考圖有本地路徑時用 `referenced_image_paths`。只能從對話取圖時用 `num_last_images_to_include`，揀能包含全部所需參考嘅最少張數，最多五張。一次用一種取圖方式。
4. 出圖後對照角色特徵。Lester 睇臉形、五官比例、眼鏡同髮型。貓睇毛色、奶白口鼻同胸口、琥珀眼、墨綠頸圈同金牌。兩者同框按真實身高同動物比例安排。

## 三、先構圖，再將圖片加落卡

- **場景由一個動作帶起。** 例如低頭翻資料、望住海港，或者隻貓挨住窗台。指明視線、手腳同道具點接觸，令角色同桌椅、窗台同地面共享同一個視角。人物邊緣、接觸陰影同環境反光要跟同一光源。
- **先預留標題同數字嘅位置。** 以 4:5 直幅定構圖，按實際行數同字量要求低細節區。封面可將人物放下半或右側，左上留空。資訊卡可將角色縮細或用空景，將最清楚嘅區域留畀資料。
- **生成無字底圖。** 用滿版裁切帶入同一場景，按需要用 `object-fit: cover` 同 `object-position` 鎖定面部、眼神同關鍵動作。標題、數字、圖表、來源、免責同 CTA 用獨立排版層加上。
- **讓光線幫文字拉開對比。** 先用天空、霧、窗光或淺牆形成留白。文字位仍然太花，就加局部漸層或一塊貼合文字範圍嘅底色。檢查裁切後有冇硬邊、錯光或懸空感，有問題就返去調整原場景。
- **一套色溫，多個鏡頭。** 以封面定地點同材質。故事頁轉手部或桌面近鏡，清單頁加可讀嘅低細節位，收尾頁用人物同貓嘅互動。按每頁分鏡安排角色姿勢。

### 生成提示例子

> 用固定 Lester 同銀灰虎斑貓參考。畫一幅 4:5 暖紙半寫實插畫，Lester 喺維港窗邊木枱低頭翻資料，銀灰貓挨住窗台。畫同方向嘅窗光、桌面反光同接觸陰影。人物同貓排喺下半，左上留一塊低細節淺色區放主標同兩行副文，右下預留帳號位。輸出無字底圖。

## 四、實戰範例／MPF 愈早管理，愈著數

| 頁面 | 圖片點幫讀者理解 |
|---|---|
| 封面 | Lester 喺維港窗邊翻資料，貓喺窗台。左上放得益主句 |
| 故事 | 將視角拉近枱面，Lester 用手指住資料解說。人物例子用匿名敘述 |
| 試算 | 用同場景空景承托資料。條形、單位同假設排到一眼睇清 |
| 三項檢視 | 貓喺邊緣探頭，以視線帶去投資內容、收費、同類表現清單 |
| 對比圖 | 用低細節圖層，畀對照欄、數字同來源留足位置 |
| 收尾 | Lester 同貓有自然互動。上半畀邀請句同 CTA |

條形圖用同一個零點同尺度，長度按實際數值。主數字同單位一齊排版，將試算假設同風險提示放喺圖表附近。

## 五、交付前睇原圖同手機縮圖

- 逐張睇裁切、角色比例、光線銜接同文字區。匯出後確認每張 PNG 係 **1080×1350**，HTML 預覽載到需要嘅底圖。
- 按[品牌可讀性標準](brand.md)檢查文字所在位置嘅對比。正文至少 4.5:1，大字至少 3:1。數字、單位、來源同免責都要睇得清。
- 縮到約 **335–390px 寬**，順序睇封面、資訊最密嘅卡同收尾。檢查主標第一眼讀到，然後逐張對返原稿嘅斷行、數字、假設、來源同 CTA。
