# 實操手冊（Playbook）

> `brand.md`／`layouts.md` 講「規則係乜」；呢份講「真實出圖時會中咩伏、點樣避」。
> 全部嚟自實戰，附量到嘅數字。改模板或出新題材前，先掃一次相關嗰節。

---

## 一、出圖流程（每次照跑）

```
文字稿＋A／B／C 畫面方案（等用戶拍板）
→ 需要新場景或角色動作時，按 images.md 定分鏡同生成底圖
→ 生成 deck.html
→ check-fit（溢出）＋ check-orphans（孤字）
→ check-source（模式 B）＋ check-compliance
→ build-embed-fonts.py → 試改原稿冇用過嘅字同匯出
→ export-png.py → export-pdf.py（4:5 ＋ --a4）
→ check-contrast.py out/
→ 目視：縮圖總覽 ＋ 放大最密嗰張
```

**最後嘅目視唔可以慳。** 工具捉到溢出、孤字、違規、低對比，捉唔到「某個 class 漏咗令大字縮細」呢類事（見第三節案例）。

## 二、單張懶人包（實戰：平安三寶）

| 問題 | 點發現 | 點修 |
|---|---|---|
| 初版溢出 173px | `check-fit` | 刪同標題重複嘅副題、三條說明各壓成一行，**字級一級都冇降** |
| 標題「遺囑」底下寫「有寫受益人…」 | 目視 | 壓縮文案**唔可以壓走主詞**——補返「**保單**有寫受益人」，否則客戶會讀成「遺囑寫受益人」 |
| 「一失智就失效」 | 內容覆核 | 改「失能」——涵蓋中風昏迷，唔只認知障礙症，亦同標題一致 |
| 句尾斷出孤字「庭。」 | `check-orphans` | 改並列句「等半年、上法庭」，保留「可能要」嘅不確定語氣 |
| 霧心對比 2.99:1 觸警告 | `check-contrast` | `.glow` 透明度 .17→.13，回到 3.02:1；**唔使改字級** |
| `check-fit` 永遠量到 0 | 版面明顯爆但工具話 OK | `.pack-body` 要 `flex:0 0 auto`，唔好 `flex:1`；多餘空間交畀 `.ruler` 嘅 `margin-top:auto` |

**單張嘅本質係「提醒」，唔係「講解」。** 客戶話「睇唔明」時，正確反應係拆輪播，唔係喺同一張塞更多字。

## 三、多張輪播（實戰：7 張詳細版）

1. **封面漏 `cover` class 係最陰險嘅伏。**
   `.cover .hand`／`.cover .title` 靠 **card 元素上嘅 `cover` class** 生效，唔似其他版型靠 `.blk`。
   漏咗 → 138px／88px 大字縮成細字（`cover-body` 高度 205 vs 正確 582），
   而 `check-fit` **唔會報錯**。所以一定要做縮圖總覽目視一次。

2. **多版型輪播嘅垂直置中**：
   `.blk{flex:0 0 auto; margin-top:auto; margin-bottom:auto}` ＋ `.ruler{margin-top:0}`。
   咁樣內容置中，而 `check-fit` 仍量到真實溢出。

3. **表格欄寬**：`c4` 第 4 欄原本 `.4fr` 只放紅點。要放中文（例如「邊個話事」）
   就改 `1.5fr 1fr 1fr .9fr` ＋ `column-gap:14px`，否則長詞會同下一欄連成一串
   （「預設醫療指示三種末期」）。太長嘅格內文字要縮（「銀行同物業」→「銀行物業」）。

4. **自動上色嘅關鍵字會被 inline 拆行**，變成「受／益人」孤字。
   加 `em.hl.kw{white-space:nowrap}` 一勞永逸。

5. **縮圖總覽唔好放喺 `out/`**：`check-contrast.py` 會當佢係多咗一張卡，量到假警告。
   放專案根目錄。

6. 同款版型唔連續；文字重嘅（table／pack）之間插留白多嘅（statement／cover）。

## 四、模板維護（改完實戰卡記得回流）

實戰入面調好嘅值，如果唔回流 `assets/template.html`，下次出新卡會重複犯同一個錯。
已回流嘅包括：

- `.num-body .numcap` 間距 52 → **84px**（大數字唔再貼住說明句）
- `.end-body .cta` padding 20/40 → **26/52**（細框唔再似按鈕）
- `.cover .book` 字距 .12 → **.06em**（中文硬規則）
- `.top .r`、`.end-body .slots` 由等寬體改 **楷體**（呢兩個位實戰成日放中文；
  等寬體冇中文字形，fallback 會令中英字體唔同、顯得散）
- 對照卡新增 **`.cmp-foot` 結論行**：對照版型主體覆蓋率只有約 39%，
  冇落點會令兩欄浮喺霧入面
- **宣言卡刻度尺退場**：`.card[data-type="statement"] .ruler{display:none}`，宣言要更靜

改模板前建議備份一份，改完用 8 款示範卡跑一次 fit／orphans／contrast。

## 五、內容與合規（實戰原則）

- **浮動或時效敏感嘅數字唔上圖**：監護人每月上限、服務收費、累積捐贈額、法定分配額呢啲會變。
- **真實個案唔上圖**（授權風險），改寫成通用機制描述。
- **官方資料未見嘅講法唔印**：例如講座提到嘅時限，查唔到官方依據就唔好寫。
- 講座筆記寫「當年 X 月 X 日生效」要**查證具體年份**——可能其實係今年，唔係舊聞。
- 軟性分享版：**零 CTA**。收尾行動係客戶自己做嘅（「先同屋企人講一聲」），唔係「搵我」。
- 配文收尾問**生活場景**（「你身邊有冇人試過幫屋企人去銀行攞錢，先發現簽唔到名？」），
  唔好問「有冇興趣了解多啲」——後者係推銷句式。
- **輪播配文要先報代價**（「7 張圖，大概 3 分鐘」），再主動畀捷徑
  （「趕時間淨係睇第 3 張對照表都得」），否則 7 張會令人卻步。

## 六、環境伏位

- **Git Bash 雙引號入面跑 `python -c` 嘅 regex 會靜默失效**（輸出空、冇報錯）。
  要分析就寫成 `.py` 檔再跑，或者直接用搜尋工具。
- `file://` 開 HTML 會靜默載唔到本地字型（CORS），所有要開瀏覽器嘅腳本都行 `_serve.py`。
- 成品打包完整字型俾預覽同改字共用。原稿用精簡字型匯出，新增字符會載入對應嘅完整字型。換字型或改模板後先重新打包。

## 七、字型來源與授權

`assets/fonts/` 兩款都係開源中文字型，以 SIL Open Font License 發佈，可隨專案分發：

- **Iansui（芫荽）**：手寫感楷體，用喺每張卡一句嘅手寫主張。
- **LXGW WenKai TC（霞鶩文楷）**：正文楷體，帶溫度。

按題材選用本地 Noto Serif TC、JetBrains Mono 或其他已授權字型。要俾用戶離線改字嘅成品，將卡片用到嘅完整字型內嵌，預覽同匯出都用同一份字型資料。
